Privacy policy

Last updated: September 24, 2026.

local-ai rclone is a personal desktop OAuth application used only by its owner with rclone. It requests Google Drive access so the local rclone process can locate a designated folder and read or update the existing files used for the owner's local note sync.

Google user data

Google Drive file metadata and content are processed locally by rclone for this sync. OAuth credentials are kept in the owner's local rclone configuration. This website does not receive Google Drive files or OAuth credentials. The application does not sell or share Google user data with third parties.

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Control and contact

The owner can stop using the application and revoke its Google account access at Google Account connections. Questions about this policy can be raised through the project issue tracker.
